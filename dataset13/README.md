# 🦠 Global Antibiotic Resistance & Infectious Disease Intelligence (2010–2025)

## Overview
18,000+ AMR surveillance records spanning 50 countries, 25 priority pathogens, 
and 16 years. Combines resistance rates, incidence, mortality, antibiotic use 
(DDD), economic burden, and One Health linkages — the most comprehensive 
synthetic AMR dataset on Kaggle.

## Files
- amr_records.csv — Full record table (~18K rows, 27 columns)
- annual_global_trends.csv — Year-by-year global AMR metrics
- country_profiles_2025.csv — Country-level 2025 snapshot with rankings
- pathogen_summary.csv — Per-pathogen resistance profiles with trend slopes
- antibiotic_use_trends.csv — DDD trends by income group and year
