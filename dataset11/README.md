# 🎮 Video Game Sales & Metacritic Intelligence (1980–2026)

## Overview
50,000 video game records spanning 47 years of gaming history across 33 platforms, 51 publishers, and 20 genres. Combines regional sales (NA/EU/JP/Other/Global), Metacritic critic and user scores, ESRB ratings, publisher intelligence, and engineered columns not found in existing public datasets.

## Files
- games.csv — 50,000 games with 35 features
- genre_summary.csv — 20 genres aggregated
- platform_summary.csv — 33 platforms aggregated
- publisher_summary.csv — 51 publishers ranked
- yearly_trends.csv — 1985-2026 year-over-year trends
