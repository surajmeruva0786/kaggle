# 🔥 Global Wildfire Intelligence (2001-2026)

## Overview
Satellite-detected wildfire events across 42 fire-prone regions in 20+ countries, covering 26 years of global fire activity. Each record combines MODIS/VIIRS satellite detection data, burn area estimates, emissions calculations (CO2, PM2.5, PM10, CO, CH4), weather conditions at fire time, drought index, and impact metrics (structures, evacuations).

## Files
- wildfire_events.csv — Individual fire events with all features
- annual_global_summary.csv — Year-by-year global aggregates (2001-2026)
- country_summary.csv — Country-level fire statistics
- regional_seasonality.csv — Monthly fire patterns by region
